Codey Companion 管理台

Codey · 把 AI 用量戴在手腕上

Codey = Claude Code / Codex 用量 + 会话监视器,跑在 M5Stack StopWatch 圆屏上, 配 Mac companion(设备端语音输入、Web 管理台、ngrok 远程)。一眼掌握每个会话的模型、上下文、 Tokens 速率与内存,空闲时随手对手表说话即可把转写粘进聚焦窗口。

首次安装 · 五步上手

按顺序走一遍即可点亮手表并开启语音输入。命令在 Mac 终端执行。

1
Mac 起服务
在仓库根目录启动 companion 后台服务(管理台 / 状态 / ASR 一并就绪)。
cd companion && ./deploy.sh start --bg
2
授权辅助功能
系统设置 → 隐私与安全性 → 辅助功能,勾选运行服务的终端 / Python, 否则语音转写无法粘贴到聚焦窗口。
3
下载 sherpa 模型(本地 ASR)
按 README 的「ASR 模型」一节下载模型,解压放到 companion/models/; 想纯云端转写可在「配置」里把引擎切到 doubao。
4
手表配网
首次上电手表开 Codey-Setup 热点 → 手机/电脑连上 → 浏览器打开 192.168.4.1 → 选择与 Mac 同一局域网的 Wi-Fi 并填密码。
5
(可选)远程访问 ngrok
想在外网连回家里的 Mac,用 ngrok 发布用量与 ASR 通道;详见 README「远程访问」一节。

运行期配置

改动即时落盘到 companion/data/config.json。显示项 / 刷新间隔立即生效; 引擎 / 粘贴改动在下一次语音会话生效。
