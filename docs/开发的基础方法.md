# StopWatch 开发基础方法

基于 **arduino-cli** 的 M5Stack StopWatch（SKU C152，ESP32-S3）应用开发指南。环境已搭好并在真机验证通过，本文档教你如何在此基础上开发自己的程序。

---

## 1. 概述

| 项目 | 值 |
|------|----|
| 设备 | M5Stack StopWatch（ESP32-S3R8，16MB Flash + 8MB PSRAM） |
| 屏幕 | 1.75" 圆形 AMOLED，466×466，CST820B 触摸 |
| 其它外设 | BMI270 六轴 IMU、RX8130CE RTC、ES8311 音频（麦克风/喇叭）、震动马达、2 个按键 |
| 开发方式 | Arduino + `M5Unified` 库，用 arduino-cli 编译烧录 |
| 开发板 FQBN | `m5stack:esp32:m5stack_stopwatch` |
| 连接/烧录 | USB-C，走 ESP32-S3 原生 USB-Serial/JTAG，**免驱动、免手动下载模式** |

---

## 2. 环境组成（已安装）

- `arduino-cli`（Homebrew 安装）
- M5Stack ESP32 核心：`m5stack:esp32`（含 StopWatch 专属板型）
- 库：`M5Unified`、`M5GFX`
- arduino-cli 已全局配置代理 `network.proxy = http://127.0.0.1:7892`（装库/更新走代理，避免 GitHub 下载卡死）

无需重复安装。换台机器重建时，参考第 9 节末尾的「从零重建」。

## 4. 核心开发循环

只需记住这几条命令（在项目根目录执行）：

```bash
# 改完代码后，编译 + 烧录（默认烧 sketches/hello_stopwatch）
./scripts/flash.sh

# 烧录指定程序
./scripts/flash.sh sketches/你的程序

# 看串口输出（Ctrl-C 退出）
./scripts/monitor.sh

# 只编译、不烧录（快速检查能否通过编译）
./scripts/build.sh sketches/你的程序
```

- 端口会自动探测（`/dev/cu.usbmodem*`）；如需指定：`./scripts/flash.sh sketches/你的程序 /dev/cu.usbmodemXXXX`
- 首次编译较慢（要编译 M5GFX 等，约 1~2 分钟），之后有缓存会快很多。

## 5. 新建一个自己的程序

1. 在 `sketches/` 下建一个**同名**文件夹和 `.ino`，例如 `sketches/myapp/myapp.ino`。
2. 写入最小骨架：

```cpp
#include <M5Unified.h>

void setup() {
  auto cfg = M5.config();
  M5.begin(cfg);                 // 初始化屏幕/按键/电源等全部板载硬件

  M5.Display.setRotation(0);
  M5.Display.setTextColor(TFT_WHITE, TFT_BLACK);
  M5.Display.setTextDatum(middle_center);
  M5.Display.setTextSize(2);
  M5.Display.fillScreen(TFT_BLACK);
  M5.Display.drawString("My App", M5.Display.width() / 2, M5.Display.height() / 2);

  Serial.begin(115200);
  Serial.println("myapp booted");
}

void loop() {
  M5.update();                   // 每个循环刷新按键/触摸/IMU 状态
  // 你的逻辑
  delay(10);
}
```

3. 烧录：`./scripts/flash.sh sketches/myapp`

> 关键：`M5.begin()` 必须在最前；`M5.update()` 必须在 `loop()` 里每轮调用，否则按键/触摸不会更新。

## 6. 用 M5Unified 操作硬件

所有板载硬件都通过全局对象 `M5` 访问：

```cpp
// —— 屏幕（圆形 AMOLED，466×466；M5.Display 即 M5GFX 画布）——
M5.Display.fillScreen(TFT_BLACK);
M5.Display.drawString("hi", cx, cy);
M5.Display.fillCircle(233, 233, 50, TFT_RED);
int w = M5.Display.width(), h = M5.Display.height();

// —— 按键（loop 里先 M5.update()）——
if (M5.BtnA.wasPressed()) { /* 按下瞬间触发一次 */ }
if (M5.BtnB.isPressed())  { /* 持续按住为真 */ }

// —— IMU（BMI270 六轴）——
float ax, ay, az;
M5.Imu.getAccel(&ax, &ay, &az);     // 加速度
float gx, gy, gz;
M5.Imu.getGyro(&gx, &gy, &gz);      // 角速度

// —— RTC（RX8130CE 实时时钟）——
auto t = M5.Rtc.getDateTime();      // t.date.year / t.time.hours ...

// —— 音频（ES8311）——
M5.Speaker.tone(2000, 200);         // 2kHz 响 200ms
// M5.Mic.record(...) 录音
```

更多 API 看本地示例（直接拷进 `sketches/` 改）：

```bash
open ~/Library/Arduino15/libraries/M5Unified/examples
```

## 7. 烧录与连接说明

- 用 USB-C 数据线连接，设备出现为 `/dev/cu.usbmodem*`，**不用装驱动**。
- esptool 会自动让芯片进下载模式，**通常不用按任何键**。
- 万一连不上 / 烧录失败：**长按 reset 键约 2 秒**，直到绿灯亮（手动进下载模式），再烧。
- 烧录成功的标志：日志出现 `Hash of data verified.` 和 `Hard resetting`。

## 8. 进阶：震动马达 / 精细电源管理

StopWatch 的震动马达、电源管理（M5PM1）和 IO 扩展（M5IOE1）需要额外的专属库：`M5PM1`、`M5IOE1`。基础显示/按键/IMU/RTC/音频用 `M5Unified` 就够了。需要时安装（会走代理）：

```bash
arduino-cli lib install M5PM1 M5IOE1      # 若库管理器里没有，则从 M5Stack 的 GitHub 克隆到 ~/Library/Arduino15/libraries/
```

## 9. 常见问题排查

| 现象 | 原因 / 解决 |
|------|------------|
| `No serial port found` | 没插线，或没出现 `/dev/cu.usbmodem*`。重插；必要时长按 reset 进下载模式 |
| 安装核心/库时下载卡住、`can't assign requested address` | GitHub 直连不稳。确认代理在跑（`http://127.0.0.1:7892`），arduino-cli 已配 `network.proxy` |
| 串口 `monitor` 看不到输出 | 程序可能只在开机/按键时打印；开机那条会在你连上 monitor 前就打完。先开 monitor 再按 reset，或在程序里周期性打印 |
| 编译报找不到 `M5Unified.h` | 库没装：`arduino-cli lib install M5Unified M5GFX` |
| 屏幕黑但程序在跑 | 可能板型库版本偏旧没认全外设；更新 `arduino-cli lib upgrade M5Unified M5GFX` |

**从零在新机器重建环境：**

```bash
brew install arduino-cli
arduino-cli config init
arduino-cli config set network.proxy http://127.0.0.1:7892
arduino-cli config add board_manager.additional_urls https://static-cdn.m5stack.com/resource/arduino/package_m5stack_index.json
arduino-cli core update-index
arduino-cli core install m5stack:esp32
arduino-cli lib install M5Unified M5GFX
```

## 10. 命令速查

```bash
# 编译 / 烧录 / 串口（封装脚本）
./scripts/build.sh  [sketch_dir]
./scripts/flash.sh  [sketch_dir] [port]
./scripts/monitor.sh [port]

# 等价的原生命令
arduino-cli compile --fqbn m5stack:esp32:m5stack_stopwatch sketches/myapp
arduino-cli compile --fqbn m5stack:esp32:m5stack_stopwatch --upload --port /dev/cu.usbmodem1101 sketches/myapp
arduino-cli monitor -p /dev/cu.usbmodem1101 -c baudrate=115200

# 查看设备 / 板型 / 已装库
arduino-cli board list
arduino-cli board details --fqbn m5stack:esp32:m5stack_stopwatch
arduino-cli lib list
```
